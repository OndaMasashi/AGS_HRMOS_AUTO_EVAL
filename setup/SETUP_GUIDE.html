HRMOS評価ツール
導入ガイド

このツールは Gemini と Claude のどちらでも動きます。導入の途中で選ぶので、先に決めておいてください。評価の精度に大きな差はありません。違うのは費用の払い方と、準備の手間です。

Claude を選ぶ場合の注意

1つの契約を複数人で共有することは規約で禁止されています。使う人それぞれが自分の契約を持っている必要があります。

学習利用の設定を確認してください。Claude の個人向けプラン（Pro / Max）は、設定が有効になっていると入力内容が今後のモデルの改善に使われます。応募者の書類を扱うため、claude.ai の設定画面を開き、「モデルの改善に役立てる」（Help improve Claude）という項目がオフになっていることを確認してください。
（Team / Enterprise 契約では既定でオフのため、この確認は不要です）

APIキーの取得

Gemini を選んだ場合のみ必要です。Claude を選んだ方は読み飛ばして構いません。

先に知っておいてください — 会社の Google Workspace は使えません

会社で契約している Google Workspace（Gmail・ドキュメント等で Gemini が使えるライセンス）と、 このツールが使う Gemini API は、まったく別の契約です。

Workspace のライセンスに含まれるのは「人がブラウザで操作する画面の中の Gemini」だけで、 プログラムから呼び出す API の利用枠は含まれていません。 そのため、Workspace とは別に、API の利用料を支払う設定（課金の有効化）が必要になります。

※ Workspace のプランを上げても、アドオンを追加購入しても、API が使えるようにはなりません。 費用は月あたり数百円程度です。

  1. ブラウザで aistudio.google.com/apikey を開く
  2. 会社の Google アカウントでログインする
  3. 「APIキーを作成」をクリックする
  4. 表示されたキー（AIza で始まる長い文字列）をコピーする
重要 — 課金の有効化

そのキーのプロジェクトで課金が有効になっている必要があります。一覧の「請求階層」列が「無料枠」になっている場合は、「お支払い情報を設定」から支払い方法を登録してください。

理由：無料枠は「入力内容を Google の製品改善に利用する」規約です。このツールは応募者の職務経歴書を送信するため、無料枠のままでは使えません。有料枠にすると「入力内容は製品改善に利用されない」扱いに変わります。費用は月あたり数百円程度です。

登録時の注意：お支払いプロファイルの種別で ［ビジネス］を選んでください。この設定は後から変更できません。

※ ここで登録する支払い方法は、Google Workspace の請求とは別建てになります。日本ではクレジットカード／デビットカードのみが利用でき、銀行口座からの引き落としには対応していません。

STEP 0

zip のブロックを解除する

必ず最初に。これを飛ばすと次の手順でファイルが実行できません

  1. 受け取った zip ファイルを右クリック → プロパティ
  2. 「全般」タブの一番下に 「セキュリティ: このファイルは他のコンピューターから取得したものです」 という表示があれば、右側の 「許可する」にチェックを入れる
  3. OK をクリック
Note

この表示が出ない場合は、既に解除済みです。そのまま次へ進んでください。

STEP 1

zip を展開する

置き場所の選び方に注意

zip を右クリック →「すべて展開」で展開します。展開先は次のように選んでください。

展開先の初期値をそのまま使うと二重フォルダになります

「すべて展開」の画面に出る展開先は、初期値が zip と同じ長い名前のフォルダ（…\AGS_HRMOS_AUTO_EVAL_20260826\）になっています。そのままだとフォルダが入れ子になって分かりにくくなります。

入力欄を C:\work に書き換えてください。C:\work\AGS_HRMOS_AUTO_EVAL\ ができます。

  • おすすめ：C:\work\ の下など、フォルダをたどる回数が少ない場所。デスクトップの奥に置くと、あとでコマンドを打つときの文字列が長くなって扱いにくくなります
  • 避けたい場所：OneDrive の中（同期の途中でファイルが動かされ、動作が不安定になります。会社のPCではデスクトップやドキュメントが OneDrive の中になっていることが多いので注意してください。エクスプローラーの左側で雲のマークが付いている場所が同期対象です）／ネットワークドライブ（Z:\ のような、他のPCにある場所）

展開すると次のフォルダができます。これ以降の説明はすべてこのフォルダが基準です。

□ 展開後のフォルダの中身

AGS_HRMOS_AUTO_EVAL\
  ├── run_scan.bat          ← 毎回の実行に使います（STEP 4）
  ├── config.yaml            ← 設定ファイル（STEP 2 で自動的に作られます）
  ├── run.py
  ├── setup\
  │     ├── install.bat       ← 導入に使います（STEP 2）
  │     └── setup_scheduler.bat
  └── data\                  ← 結果の保存先（実行すると自動でできます）
        └── reports\         ← Excel はここに出ます
STEP 2

install.bat を実行する

ここが本体。途中で4〜5回、キーボード入力を求められます

展開したフォルダの中の setup\install.bat をダブルクリックします。黒い画面が開き、順番に処理が進みます。

あなたが操作するのは下の (A)(B)(C) の3か所だけで、それ以外は自動で進みます。待っている間に画面が止まって見えても閉じないでください。

ステップ内容目安
1/8Python の確認（未導入なら自動インストール）〜5分
2/8仮想環境の作成数秒
3/8必要な部品のインストール1〜3分
4/8ブラウザ（Chromium）のインストール2〜5分
5/8設定ファイルの準備数秒
6/8ログイン情報とAPIキーの入力（手を動かす場所）1分
7/8定期実行の登録（任意）数秒
8/8自己診断1分

       ・特徴: 追加ソフト不要。ブラウザでのログイン作業もなし

    2) Claude（サブスクリプション）
       ・費用: 契約済みのプランに含まれます（使った分の追加請求はありません）
       ・必要: Claude の Pro / Max / Team / Enterprise 契約

「どちらのAIを使うか決める」で選んだ方の番号を入力して Enter を押します。何も入力せずに Enter を押すと 1（Gemini）が選ばれます。

1（Gemini）を選んだ場合

APIキーの入力を求められるので、先ほどコピーしたキーを貼り付けます。

貼り付け方

コマンド画面への貼り付けは 右クリック または Ctrl+V です。入力しても画面に表示されませんが正常です。

2（Claude）を選んだ場合

Claude Code が入っていなければ自動でインストールされます。そのあとログイン状態が確認されます。

確認に30秒〜1分ほどかかります

Claude を選ぶと、ログイン状態を確かめるために実際に1回問い合わせます。その間画面が止まって見えますが、待ってください。

すでにログイン済みなら、次のように表示されて完了です。追加の操作はありません。

□ 画面に表示される内容（見るだけ）

      OK   Claude Code: 2.1.220 (Claude Code)
      OK   ログイン済みです。すぐに利用できます。

まだログインしていない場合は、次の案内が出ます。

□ 画面に表示される内容（見るだけ）

      注意 まだブラウザでのログインが済んでいません。次の操作が必要です。

           1) スタートメニューから「コマンドプロンプト」を開く
           2) 次の1行をそのままコピーして貼り付け、Enter を押す

                "C:\Users\（あなた）\.local\bin\claude.exe"

           3) 画面の案内に従い、ブラウザで Claude にログインする
              （初回はテーマ選択などの質問が出ます。Enter で進めて構いません）
           4) 終わったら exit と入力して閉じ、
              setup\install.bat をもう一度ダブルクリックする
ログインは初回の1度だけ

一度ログインすれば以降は不要です。評価の費用は契約中のプランに含まれ、追加請求はありません。

なぜ長いパスを貼り付けるのか

Claude Code を入れた直後は、claude という短い名前ではまだ見つからないことがあります。画面に表示される実際のパスをそのままコピーすれば確実です。

このあと診断は「NG」で終わります（失敗ではありません）

ログインが済んでいなくても、インストーラは止まらずに最後まで進みます。そのため次の STEP 3 で [NG] AI評価の疎通 (claude) と表示され、最後に黄色で「セットアップは完了しましたが、未解決の項目があります」と出ます。

壊れてはいません。上の 1)〜4) を済ませてから setup\install.bat をもう一度ダブルクリックすると [OK] に変わります。

（C）定期実行の登録

➤ 画面に出る質問（答える）

      平日 12:30 / 17:30 の自動実行を登録しますか？ (y/N):

平日の 12:30 と 17:30 に自動実行したい場合は y、自分でそのつど実行したい場合はそのまま Enter。土日は実行されません。後から setup\setup_scheduler.bat でいつでも登録できます。

NG が出た場合は、その行に対処方法が書かれています。「困ったとき」も参照してください。

Claude を選んだ場合、1回目は AI評価の疎通 (claude) が NG になることがあります。STEP 2 のログイン手順（1)〜4)）を済ませてから setup\install.bat をもう一度ダブルクリックしてください。

STEP 4

実行する

ダブルクリックして、終わるまで待つ

フォルダ直下の run_scan.bat をダブルクリックします。書類のダウンロード → AI評価 → Excel出力までが自動で行われます。

□ 実行中の画面（見るだけ）

============================================================
  HRMOS - scanning for new applicants
============================================================

  This takes several minutes. Do NOT close this window.
  Progress is written to:
    C:\work\AGS_HRMOS_AUTO_EVAL\data\logs\scan_20260825_143000.log
画面が止まって見えても、閉じないでください

この後、数分から十数分のあいだ画面に何も出ません。処理は裏で進んでいます。新しい応募者が多いほど長くかかります（1人あたり十数秒 × 人数）。

間違えて閉じてしまっても壊れません。そこまでに評価が終わった人の結果は保存され、残りは次回の実行に持ち越されます（ただしその回の Excel は作られません）。

終わると次のように表示され、キーを押すまで画面が残ります。

□ 終わったときの画面（見るだけ）

  Done. Reports are in:
    C:\work\AGS_HRMOS_AUTO_EVAL\data\reports

続行するには何かキーを押してください . . .

結果は data\reports\ フォルダに Excel ファイル（ai_evaluation_日付.xlsx）として出力されます。

画面は英語ですが問題ありません

この画面はタスクスケジューラからの自動実行でも使う共通のものなので、英語のままにしています。Done と出れば成功、ERROR と出れば失敗です。失敗のときは表示されたログファイルの場所を管理者に伝えてください。

新しい応募者がいないとき

すぐに終わり、Excel は作られません。異常ではありません。このツールは前回から増えた人だけを処理します。

使い始める前に — これだけは

AI の点数だけで合否を決めないでください。最終判断は必ず人が、元の書類を見たうえで行ってください（利用規約上の要件です）。

出力される Excel と data\downloads\ の書類は応募者の個人情報です。社内のルールに従って管理してください。詳しくは運用上の注意を参照。

評価の内容を自分で変えたい場合

評価する項目、面接質問の観点、1次通過候補の判定ラインは、すべて後から変更できます。 プログラムの知識は要りません。設定ファイルをメモ帳で編集するだけです。

別ガイドにまとめています

編集のしかた、失敗しないための3つのルール、変更したあとに必要な操作、 壊してしまったときの直し方までを説明しています。

設定ガイド（応用編）— 評価基準を自分で変える →

既定の評価項目のまま使う場合、この作業は必要ありません。

任意 — メール通知を有効にする

この設定はしなくても構いません。ツールは通常どおり動き、結果は Excel に出力されます。

有効にすると、評価が終わるたびに結果のサマリと Excel が添付されたメールが届きます。 毎回フォルダを開いて確認しなくてよくなるほか、失敗したときにも通知が届くので、 自動実行にしている場合の「動いていたつもりで止まっていた」を防げます。

診断画面に「メール通知 無効」と出るのは正常です

導入直後はこの機能がオフになっています。[OK] メール通知 無効 (enabled: false) と表示されますが、異常ではありません。使わない場合はそのままで問題ありません。

送られてくるメールの種類

いずれの場合も必ず何かが届くため、「メールが来ない＝何かおかしい」と判断できます。（ただし設定した直後に一度も届かないときは、ツールではなく宛先の設定が原因のことがあります。下の注意を参照）

種類届くとき
評価結果メール新規の応募者を1名以上評価できたとき（サマリ表＋Excel添付）。AIが評価できなかった応募者がいると、件名に「評価できず N名」、本文に名前と理由が出ます。この応募者は自動では再評価されないので、HRMOSで直接評価してください
「新規なし」通知新規の応募者が0名で正常に終わったとき
失敗アラートログインに失敗した・一覧が取れなかった・評価が全件失敗したとき

設定のしかた

  1. resend.com でアカウントを作成し、APIキーを取得する
    Resend はメール送信サービスです。無料枠があり、社内の SMTP 設定は不要です。
  2. APIキーを Windows のユーザー環境変数 RESEND_API_KEY に設定する

    （打ち方はこちら）

    ▶ 入力するコマンド

    setx RESEND_API_KEY "re_xxxxxxxxxxxx"
    設定後は新しい画面を開いてから実行してください（既存の画面には反映されません）。
  3. ツールのフォルダにある config.yaml をメモ帳で開き、email: の部分を編集する

    ✎ config.yaml の編集箇所

    email:
  enabled: true                  ← false から true に変える
  from: "onboarding@resend.dev"  ← 変更しないでください
  to:
    - "宛先@example.com"         ← 受け取りたいアドレス
  subject_prefix: "[HRMOS]"
  attach_resumes: true
  notify_on_no_candidates: true
  4. 設定できたか確認する（打ち方はこちら）

    ▶ 入力するコマンド

    .venv\Scripts\python.exe run.py doctor
    [OK] メール通知　有効 / 宛先 1件 と出れば完了です。
まず「自分のアドレス」だけで試してください

from（差出人）は Resend が用意しているお試し用のアドレスです。このままだと Resend に登録したご本人のアドレス宛にしか届きません。部署の共有アドレスや上司を宛先に足すのは、自分のアドレスで届くことを確認してからにしてください。

共有アドレスにも送るには、Resend 側で自社ドメインを登録する作業（DNSの設定）が必要です。from を自社のアドレスに書き換えるだけでは送れません（書き換えると、それまで届いていた分も止まります）。

config.yaml を編集するときの注意

行頭の空白（インデント）を変えないでください。YAML という形式は字下げで構造を表すため、ずれると読み込めなくなります。日本語入力のまま全角スペースを打ってしまうのもよくある失敗です。

壊してしまった場合は doctor が「YAMLとして読めません」と教えてくれます。config.yaml.example をコピーして作り直せば元に戻せます。

経歴書の添付について

attach_resumes: true にすると、1次通過候補（○）の応募者の経歴書がメールに添付されます。この添付ファイルは伏字にしていない個人情報をそのまま含みます（ツールがAIに送るときだけ伏字にしており、原本には手を加えないため）。

社内の個人情報の取り扱いルールを確認したうえで判断してください。添付が不要なら attach_resumes: false にします。

途中で出るかもしれないメッセージ

「新しい画面で開き直してください」と表示された

異常ではありません

Python を新しく入れた直後に必ず起きます。設定の変更は新しく開いた画面にしか反映されないためです。画面を閉じて setup\install.bat をもう一度ダブルクリックしてください。2回目は Python のインストールが飛ばされるので早く終わります。

2回目は、入力済みの項目ごとに「変更しますか？ 変更しない場合はそのまま Enter (y=変更)」と聞かれます。そのまま Enter を押せば前回の入力がそのまま使われます。

最後に英語で「Some checks did not pass...」と出た

新しいエラーではありません

「やり残しがあります。直してから install.bat をもう一度実行してください」という意味で、その上に日本語で出ている案内と同じことを言っています。

画面を上にスクロールして、赤い「セットアップを中断しました」または [NG] で始まる行を探してください。

どちらも見当たらない場合は、上の日本語の案内どおりに画面を閉じて setup\install.bat をもう一度ダブルクリックすれば進みます（[NG] の行は診断まで進んだときだけ出るため、途中で止まった回には存在しません）。

「WindowsによってPCが保護されました」と出た

黒い画面がすぐ閉じてしまう

setup\install.bat は「管理者として実行」ではなく、通常のダブルクリックで開いてください。それでも閉じる場合は、install.ps1 が setup フォルダ内にあるか確認してください（zip の展開漏れ）。

困ったとき

問題が起きたら、まず自己診断を実行してください。どこでつまずいているかが1回のコマンドで分かります。

コマンドの打ち方（この文書で共通）

この先に出てくるコマンドは、すべて次の手順で打ちます。1回覚えれば以降は同じです。

  1. ツールのフォルダをエクスプローラーで開く（run_scan.bat が見えている状態）
  2. フォルダ上部のアドレス欄（C:\work\… と表示されている場所）をクリックして、文字が選択された状態にする
  3. そのまま cmd と打ち込んで Enter を押す
    → そのフォルダを開いた状態で黒い画面が立ち上がります
  4. コマンドを右クリックで貼り付けて Enter
この方法なら「フォルダの移動」が要りません

スタートメニューからコマンドプロンプトを開くと別の場所が開いてしまい、cd というコマンドで移動する必要があります。上のやり方なら最初から正しい場所で開きます。

運用上の注意

個人情報の取り扱い

出力された Excel と data\downloads\ の書類は、社内の個人情報取扱いルールに従って管理してください。

不具合が起きたときは data\debug\ に画面の写しが保存されます。応募者のページをそのまま保存するため、氏名・連絡先・経歴が含まれます。原因を確認したら削除してください（自動では消えません）。

AI の点数だけで合否を決めないでください

AI の出力は「下読み」です。最終判断は採用の担当者が元の書類を見たうえで行ってください。

これは心がけではなく、AI提供各社の利用規約が定める要件です。採用選考は「高リスク用途」に分類され、結果を使う前に有資格者が内容を確認することが条件になっています。

「○が付いた人だけ書類を読む」という運用も避けてください。○が付かなかった人を、人が見ないまま落としていることになります。

このツールには HRMOS へ自動で NG 評価を登録する機能（config.yaml の hrmos_evaluation）がありますが、初期状態では無効です。有効にすると上に書いた状態そのものになり、登録した評価は選考タイムラインに残って取り消せません（画面上に取り消しの導線が見当たらないことを実機で確認しています）。社内の採用責任者の承認を得たうえで、登録済みの応募者を定期的に人が確認する運用とセットにしてください。設定の詳細と、有効にする前の確認手順は「設定変更ガイド」の手順10にまとめてあります。

APIキーは他人に渡さない

使用量がそのまま会社の請求に乗ります。

AI Studio の画面に書類を直接貼らない

このツールは送信前に氏名・電話番号・住所を伏字にしていますが、手作業で貼るとその処理が働きません。
